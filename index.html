Verification Process

Check 1 — Watermark: Correlates the embedded PN sequence against the registered key. Score ≥ 65% = PASS.

Check 2 — Speaker: Compares MFCC cosine similarity between enrolled fingerprint and message. Score ≥ 75% = PASS.

AUTHENTIC = Both checks pass.

SUSPICIOUS = One check fails.

FAKE = Both checks fail.

Research Contribution

Existing research focuses on either speaker verification, deepfake detection, or digital audio watermarking — independently. This system integrates all three.

Voice Digital Signature Framework: Analogous to PGP for email, VocalPrint introduces a proactive signing paradigm — instead of detecting fakes after the fact, recordings carry cryptographic proof of origin.

Dual-Factor Voice Authentication: Both biometric identity (who spoke) and message integrity (unmodified signal) are verified simultaneously.

Signal Processing Pipeline
ENROLLMENT
Audio → Pre-emphasis → Framing → Hanning Window
→ FFT Power Spectrum → 40-band Mel Filterbank
→ DCT → 13 MFCC Coefficients → SHA-256 Hash

SIGNING
Audio → Compare MFCC (speaker check)
→ Generate PN sequence from fingerprint key
→ Embed spread-spectrum watermark @18-20 kHz
→ Store MSG_ID + PN sequence in registry

VERIFICATION
Audio → Extract MFCC → Cosine sim vs enrolled
→ Correlate with stored PN sequence
→ Dual pass/fail → AUTHENTIC / SUSPICIOUS / FAKE
